# ここちよナンプレ

史上もっともプレイヤーに優しくないナンプレ。

ナンプレ自体は普通に解けるのに、過剰な演出・チュートリアル・確認ダイアログ・通知がどんどん増えていく、忍耐力を試すブラウザゲームです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。スマートフォン・PC の両方に対応しています。

GitHub Pages を有効にすると、URL を共有してすぐ遊べます（Settings → Pages → Branch: `main` / `(root)`）。

## 妨害の段階

時間経過と進行度のうち、進んでいる方で段階が上がります。

| 段階 | 内容 |
| --- | --- |
| 0〜1分 | 普通のナンプレ、簡単なチュートリアル、控えめな正解演出 |
| 1〜2分 | おさらいチュートリアル、入力時の確認ダイアログ、過剰な称賛 |
| 2〜3分 | 長い正解演出、デイリーミッション、実績解除通知 |
| 3〜4分 | 応用編・上級編などのチュートリアル、アップデートのお知らせ、入力遅延、ボタン配置の変化 |
| 4分〜 | 連続ポップアップ、クリア前の最終確認、長いクリア演出、回答必須のアンケート |

すべてのポップアップは必ず閉じられるので、最後までクリアできます。

## 構成

HTML / CSS / JavaScript のみの単一ファイルです。外部ライブラリは使っていません（フォントのみ Google Fonts）。

- `Sudoku`：盤面生成・正誤判定などナンプレ本体のロジック
- `UI`：モーダルを1つずつ表示するキューとトースト通知
- `Annoy`：段階的に解放される妨害エンジン
- `Game`：画面遷移・入力・状態管理・リセット
